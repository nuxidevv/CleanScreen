# CleanScreen

Une interface TV plus propre.

CleanScreen est un projet open source visant à personnaliser les interfaces de téléviseurs compatibles et à réduire les recommandations sponsorisées lorsque le système le permet.

# Fonctionnalités prévues

* Interface moderne et personnalisable
* Thèmes visuels
* Guide de compatibilité des téléviseurs
* Assistant de configuration
* Intégrations adaptées aux systèmes compatibles

# État du projet

Prototype en développement. La détection des appareils et les modifications de l’interface nécessitent des intégrations spécifiques au téléviseur.
